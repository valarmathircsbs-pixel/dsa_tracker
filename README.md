# 🚀 DSA Practice Tracker

A simple and effective web application to track and organize your Data Structures & Algorithms (DSA) practice.

## 🌐 Live Demo
👉 https://valarmathircsbs-pixel.github.io/dsa_tracker/

---

## 🧠 Problem

While practicing DSA on platforms like LeetCode and GeeksforGeeks, I noticed:

- I couldn't remember how I solved problems  
- I didn't know which topics I was weak in  
- I sometimes re-solved the same problems unknowingly  

---

## 💡 Solution

This project helps track and manage problem-solving in a structured way.

---

## 🔧 Features

- ➕ Add, ✏️ Edit, ❌ Delete problems  
- 📊 Categorize by Difficulty (Easy, Medium, Hard)  
- 🧩 Organize by Topics (Arrays, Strings, Trees, Graphs)  
- ✔ Mark problems as Solved / Unsolved  
- 🔍 Search problems  
- 🎯 Filter by difficulty, topic, and status  
- 🔄 Sort problems  
- 📈 Progress tracking with stats  
- 💾 Data persistence using localStorage  
- 🌙 Dark mode support
